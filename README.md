## About NumPy

NumPy (Numerical Python) is a Python library used for fast numerical calculations and working with arrays. It is widely used in Data Science, Artificial Intelligence, and Machine Learning.

## Installation

Install NumPy using pip:

```bash
py -m pip install numpy
```

Check the installation:

```python
import numpy as np

print(np.__version__)
```

## Example

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print("Array:", arr)
print("Mean:", np.mean(arr))
print("Maximum:", np.max(arr))
print("Minimum:", np.min(arr))
```
